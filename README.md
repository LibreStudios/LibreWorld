# LibreWorld
LibreWorld is an open-source, 3D social sandbox massively multiplayer online (MMO) game developed in the Godot engine. Designed with a free and open-source software (FOSS) philosophy, the game draws inspiration from social sandbox titles like other games while featuring a distinct, low-poly aesthetic with rounded avatars and floating limbs.
